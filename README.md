## 📌 About

## 🎨 Improvements Made

- **Navbar** — Cleaner layout with logo, centered links, and a hamburger menu for mobile
- **Hero Section** — Two-column layout with bold tagline, description, and an "ORDER NOW" CTA button
- **Category Cards** — Grid layout showing Cakes, Tubs, Scoops & Sundaes with image, price, and buy button
- **Special Offers** — Dedicated section highlighting discounts to encourage orders
- **Footer** — Organised contact info, location, and brand specialities in one place
- **Visual Design** — Used BR's pink & brown brand colors, consistent spacing, and clear typography
